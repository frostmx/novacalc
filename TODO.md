# NovaCalc — TODO

**Глобальная задача:** калькулятор производственных цепочек для игры Nova Lands
(`C:\Program Files (x86)\Steam\steamapps\common\Nova Lands`).

**Источники данных:**
- Файлы игры (основной источник) — см. «Пайплайн данных» ниже
- Вики для сверки: https://nova-lands.fandom.com/wiki/Items
  (страницы фандома отдают 402, но работает API: `https://nova-lands.fandom.com/api.php?action=parse&page=<Page>&prop=wikitext&format=json`)

**Локализация:** весь текст только через ключи локализации игры (`nameKey`/`descKey`).
Первый язык — английский (`data/locale/en.json`), остальные переводы добавим разом позже.

          `productionSpeed` здания (0.8 у печей/рефайнери/ассемблеров, 1.0 у остальных) — базовый множитель, вики его
          не учитывает → её время для этих зданий занижено на 25%. Пример: титан в Adv. Furnace с Hot Bricks и рубином

          в реальном времени и только пока растение растёт / плодоносит; выросшее или с полным запасом — таймеры стоят ✓.

Игра на Unity 2022.2.8f1 / IL2CPP, typetree вырезаны → схемы восстанавливаются из `GameAssembly.dll` + `global-metadata.dat`.

```
pip install -r tools/requirements.txt
python tools/extract_game.py "C:/Program Files (x86)/Steam/steamapps/common/Nova Lands" data/raw
python tools/build_data.py   "C:/Program Files (x86)/Steam/steamapps/common/Nova Lands" data/raw data [en ru_RU ...]
```

- `data/raw/cls_<Class>.json` — сырой дамп MonoBehaviour-ов, ссылки вида `file:pathId`
- `data/gamedata.json` — нормализованные items / recipes / buildings / modifiers
- `data/locale/<lang>.json` — тексты только для используемых ключей
